# CC0 Guns & Explosives production assets

These models originate from the **Free CC0 Guns & Explosives Pack** by 3dmodelscc0.

Original pack:
https://3dmodelscc0.itch.io/free-cc0-guns-explosives-pack

The GLB files used by this project come from BoQsc's material-fixed Blender conversion release:
https://github.com/BoQsc/cc0-guns-explosives-pack-glb/releases/tag/0

The optimized `m4a1.glb` was migrated from Zombie Town Online's local CC0
asset set. It was converted from the same original pack with embedded glTF 2.0
PBR textures resized for browser/runtime use.

The source pack and conversion repository identify the assets as **CC0 1.0 Universal / public domain**. Attribution is not required, but the source information is kept here for provenance.

Approved and legitimate Zombie Town mappings:

- `makarov.glb` -> M1911 gameplay slot
- `ak47.glb` -> AK-74u gameplay slot
- `m4a1.glb` -> M4A1 gameplay slot (replaces the former AN-94 slot)
- `suomi_kp.glb` -> MP5 gameplay slot
- `grease_gun.glb` -> M3 Grease Gun gameplay slot
- `luger.glb` -> Luger P08
- `flare_gun.glb` -> Flare Gun
- `shotgun.glb` -> Pump Shotgun / REM870 gameplay slot
- `sniper.glb` -> DSR-50 / Sniper Rifle gameplay slot

The source pack's shotgun is pump-action and is intentionally not used for the
double-barrel Olympia. The other Zombie Town weapon slots remain procedural
unless a genuine matching production asset is added from an approved source.
