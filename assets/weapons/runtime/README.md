# Runtime weapon assets

This folder contains only weapon assets that are intentionally exposed to Godot's importer.

Raw CC0 source GLBs remain under `assets/weapons/cc0/`, which is ignored by Godot. Production models are promoted into this folder one at a time and live-tested before the next model is added.

Current validation stage: Makarov import only. Production viewmodel loading remains disabled until the editor import is confirmed stable.
